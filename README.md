# 🦫 ตีคาปิบารา ก-ฮ แสนสนุก (Thai Consonants Whack-a-Mole)

เกมเว็บแอปพลิเคชันเพื่อการศึกษาสำหรับเด็กอนุบาลและปฐมวัย ฝึกทักษะการฟังและการจดจำพยัญชนะไทย ก ไก่ ถึง ฮ นกฮูก (44 ตัว) ผ่านเกมตีน้องคาปิบาราสุดน่ารัก รองรับทั้งการเล่นแบบแตะหน้าจอ (Touch) และโหมด AR ตรวจจับมือผ่านกล้อง (Hand Tracking ด้วย MediaPipe Hands)

---

## ✨ จุดเด่นของเกม (Features)

- 🦫 **ตัวละครน้องคาปิบาราสุดน่ารัก:** ภาพเวกเตอร์การ์ตูน Capybara พร้อมส้มยูซุบนหัวและแอนิเมชันเด้งดึ๋ง
- 🇹🇭 **พยัญชนะไทยครบ 44 ตัว (ก-ฮ):** ป้ายตัวอักษรขนาดใหญ่ ชัดเจน อ่านง่าย เหมาะกับเด็กปฐมวัย
- 🔊 **ระบบฝึกฟังเสียง (Listening Skills):** ระบบอ่านออกเสียงพยัญชนะไทยตามมาตรฐาน (Web Speech API) พร้อมปุ่มกดฟังเสียงซ้ำ
- 📷 **รองรับ AR Hand Tracking:** สามารถเปิดกล้องใช้ปลายนิ้วชี้เพื่อตีคาปิบาราได้โดยไม่ต้องสัมผัสหน้าจอ
- 🎵 **เพลงประกอบและเสียงเอฟเฟกต์:** ดนตรีประกอบสไตล์ Arcade Synthesizer สนุกสนาน พร้อมเอฟเฟกต์เมื่อตีถูก/ตีผิด/โบนัสคอมโบ
- ⚡ **ไฟล์เดี่ยวจบ (Single File):** ใช้งานได้ทันทีบนเว็บเบราว์เซอร์ทุกอุปกรณ์ ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

---

## 🎮 วิธีการเล่น (How to Play)

1. เลือกความยาก (ง่าย / กลาง / ยาก) และเลือกโหมดการควบคุม (**🖱 เล่นแบบแตะหน้าจอ** หรือ **📷 เปิดกล้องใช้มือ**)
2. ฟังเสียงพยัญชนะที่ระบบอ่าน เช่น *"กอ ไก่"*
3. มองหาคาปิบาราที่มีป้ายตัวอักษรตรงกับเสียง (เช่น **ก**) แล้วแตะหรือชี้นิ้วค้างไว้เพื่อตี
4. สะสมคะแนนและคอมโบภายในเวลา 60 วินาที!

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **HTML5 & CSS3** (Responsive, Keyframe Animations, Glassmorphism UI)
- **Vanilla JavaScript** (Game Loop, Web Audio API Sound Engine)
- **MediaPipe Hands** (Real-time Hand Landmark Tracking)
- **Web Speech API** (Thai Text-to-Speech)
